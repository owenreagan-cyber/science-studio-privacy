What it is

A production studio for science teaching.

Science Studio helps educators turn source-aligned curriculum into classroom-ready artifacts: unit maps, guided notes, investigations, assessments, and presentation decks. The workflow is built around review, versioning, and explicit approval — not one-click publishing.

01

Curriculum, composed

Build units from source material, with guided notes as the primary student reference and presentations designed to match the notes.

02

Presentation-ready

Produce editable decks and export approved candidates for native Google Slides when a presentation is ready for review.

03

Deliberate by default

Dry runs, allowlists, and explicit execute steps keep every write visible, bounded, and reversible by the person who authorized it.

Google Drive + Google Slides

A narrow bridge, not a back door.

The integration runs locally under the Google account an educator authorizes. It is designed to create and verify its own staging files — not to browse, reorganize, or publish a Drive library.

The integration

What happens when you publish.

A standard run is intentionally small: one approved source file goes in, one staged presentation comes out, and the result is checked before anyone treats it as ready.

What it does

  • Creates a dedicated staging folder in the authorized account's Drive.
  • Uploads an approved PPTX and converts it to a native Google Slides presentation.
  • Records a source hash so repeat runs reuse the same staged copy.
  • Reads slide structure, text, notes, and optional thumbnails to verify the result.
  • Can insert approved video objects into allowlisted staged decks.
  • Stops before promotion: a staged deck is not classroom-live automatically.

What it does not do

  • It does not scan or browse unrelated Drive files.
  • It does not use drive.file to reach classroom files it did not create.
  • It does not delete files or empty your trash.
  • It does not promote a staged deck into a live classroom deck.
  • It does not send Google user data to Science Studio servers.
  • It does not sell data, use it for advertising, or use it to train generalized AI models.
Google API scopes used by the Science Studio integration
Permission What it allows How Science Studio uses it
drive.file Access only to Drive files this integration creates or that you explicitly open with it. Create the staging folder, upload and convert approved sources, and manage its own staged files.
presentations.readonly View Google Slides presentations and their content. Read slide structure, text, speaker notes, revision metadata, and thumbnails for verification.
presentations View and edit Google Slides presentations. Optional media inserter only: add an approved video to an approved staged deck, then verify it.
openid + userinfo.email Confirm the signed-in Google account and its email address. Check the authorized account before a write. The email is not sent to Science Studio.

Privacy by design

Your Drive. Your account. Your call.

OAuth tokens stay on the local machine, outside the project repository, with owner-only file permissions. The integration does not operate a server, and it does not send Google user data to us. You can revoke access at any time from your Google Account.
